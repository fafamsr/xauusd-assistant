# XAUUSD FAFA — mode gratuit
Site statique utilisable sur GitHub Pages. Les indicateurs sont calculés localement sur les bougies fournies par l'utilisateur; aucune API ni clé n'est utilisée.
Important: pas de flux de prix en direct, pas de news automatiques et pas de conseil financier. Ne trade pas sur l'exemple fictif.
Déploiement: déposer le contenu de cette archive à la racine du dépôt GitHub, conserver le dossier public, puis Settings > Pages > Deploy from a branch > main > /(root).
