# XAUUSD FAFA automatique M5/M15/M30
Site statique GitHub Pages; aucune saisie utilisateur, aucun exemple fictif, aucun appel ChatGPT.
La page utilise l'API publique biquote.io pour le dernier tick XAUUSD et les bougies OHLC M5, M15 et M30. Elle calcule EMA20/50, RSI14, ATR14 et supports/résistances approximatifs sur les bougies clôturées. Si les données manquent/ sont périmées, affiche NO TRADE.
Le flux tiers peut être différent du broker MT5; aucune garantie de prix tradable ni conseil financier.
Déploiement: remplacer les fichiers du dépôt par le contenu de cette archive, conserver le dossier public, puis Settings > Pages > main > /(root).
